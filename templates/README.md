# PowerPoint Template

The editable `gtm-canvas-template.pptx` is the intended binary template for the 14-slide output described in `../output/pptx-generation-spec.md`.

**Status:** The binary template has not yet been generated or committed. This directory currently contains the specification reference only.

When adding the template, verify that:
- It contains exactly 14 slides.
- All objects are native editable PowerPoint elements.
- Slide 1 contains the 12-block 4 × 3 overview.
- Slides 2–13 contain one worksheet per canonical block.
- Slide 14 contains Strategy Integrity & Next Steps.
- The file opens successfully in PowerPoint and a compatible editor.

Do not add a screenshot-based or flattened deck as a substitute.
